**QuietForgeTools** — free offline diagnostic for WordPress contact / enquiry / quote forms.

## What it is

A single-page browser checklist. You manually mark each practical check:

- Pass · Fail · Not sure · N/A

The page then builds a copyable diagnostic summary (failed items, uncertain items, recommended next investigation).

**It does not scan or inspect your website automatically.** No uploads, no backend, no accounts.

## Privacy

Answers stay in the current browser tab. No cookies, no analytics, no localStorage, no external APIs. Refresh clears marks.
